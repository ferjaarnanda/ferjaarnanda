## Notes
- No `assets/` folder is required; every local image is kept at the repository root for easy GitHub upload.
- Development-language and brand icons use Devicon SVGs via CDN.
- The SQL image is the supplied SQL asset.
- cPanel uses a web-sourced cPanel brand image; cPanel publishes downloadable logo assets in its official brand guide.
- Hosting, server, domain, HTTPS/SSL, deployment, and SEO images are web-sourced visual assets stored locally in the root so the portfolio does not depend on a generated placeholder.
- CV and profile photo remain root-level files.
