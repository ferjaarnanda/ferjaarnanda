FAQ

Berapa harga pembuatan website?

Harga mulai dari Rp 750K untuk paket Bronze hingga Rp 3.500K untuk paket Diamond, tergantung kebutuhan fitur dan kompleksitas sistem.

Berapa kali bisa revisi?

Jumlah revisi disesuaikan dengan paket pilihan, umumnya berkisar antara 2 hingga penyesuaian minor tanpa batas sebelum tahap finalisasi.

Apakah sudah termasuk domain dan hosting?

Ya, semua paket standar telah mencakup domain (.com / .id) serta cloud hosting aktif selama 1 tahun pertama beserta sertifikat SSL.

Berapa lama pengerjaannya?

Waktu pengerjaan berkisar antara 3 hingga 14 hari kerja tergantung pada kelengkapan materi konten dan kompleksitas sistem.

Bagaimana biaya perpanjangan?

Biaya perpanjangan tahun berikutnya hanya dikenakan untuk pembaruan domain dan sewa server hosting sesuai tarif reguler penyedia layanan.
